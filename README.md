# Diver Calculator

Android-приложение для водолаза по **ПВС ВМФ-2002**: выбор дыхательной смеси и предельной глубины,
режимы декомпрессии, приготовление смеси и смежные (удлинённые) режимы.

<img src="docs/screenshot.png" width="300" alt="Скриншот приложения">

## Вкладки

1. **Смесь** — воздух, КАС, КВС или медицинский кислород; для КАС и КВС — процент кислорода.
   Показывает предельную глубину спуска и pO₂.
2. **Декомпрессия** — режим по таблицам ПВС для выбранной смеси, глубины и экспозиции:
   рабочие, повторные, аварийные, высокогорье, барокамера; удлинённые режимы по неблагоприятным
   факторам; воздушная или кислородная декомпрессия.
3. **Приготовление** — последовательность приготовления смеси: кислород добавляется в баллон
   с основным газом (азот или воздух), а не наоборот; учёт остатка в баллоне, анализы по ПВС.
4. **Смежные режимы** — по две строки таблицы короче и длиннее основного режима.

Вкладки связаны: данные одной ограничивают выбор в остальных. Если подходящего режима нет,
приложение сообщает, что спуск недопустим.

## Откуда данные

- Таблицы режимов декомпрессии 1–6, допустимые сроки дыхания кислородом и приготовление 40 % КАС —
  ПВС ВМФ-2002 (электронная копия). Таблицы извлекаются скриптом [`tools/build_pvs.py`](tools/build_pvs.py)
  в `app/src/main/assets/pvs.js`.
- В копии найдены опечатки — см. [`docs/pvs-errata.md`](docs/pvs-errata.md). Однозначные исправлены,
  в спорных случаях принят более длинный вариант; такие режимы помечены в приложении значком ⚠.
- Для КАС и КВС с процентом, отличным от 40 %, в ПВС таблиц нет. Приложение считает предельную
  глубину по pO₂ = 0,22 МПа (как у 40 % КАС на 45 м), а декомпрессию — по эквивалентной воздушной
  глубине. Это расширение за рамками ПВС, и приложение об этом предупреждает.

## ⚠️ Безопасность

Приложение — вспомогательный инструмент. Оно не заменяет водолазного специалиста,
врача-спецфизиолога и печатное издание ПВС. Смесь перед спуском обязательно проверяется
газоанализатором.

## Установка

Скачайте APK из раздела [Releases](../../releases). Нужен Android 8.0 или новее.

## Сборка

Нужны JDK 17 и Android SDK (platform 35).

```sh
./gradlew assembleRelease
```

Интерфейс — обычная HTML-страница в `app/src/main/assets/` (`index.html`, `app.js`, `pvs.js`),
её можно открыть в браузере. Для подписанной сборки создайте `keystore.properties` в корне проекта:

```properties
storeFile=../your-release.jks
storePassword=...
keyAlias=...
keyPassword=...
```
